# orca-russian

Русский языковой пакет (ru-RU) для [Orca](https://github.com/stablyai/orca).

## Статус

Почти полное покрытие переводимого каталога интерфейса Orca:

- **13 574 / 13 579** переводимых строк переведено (99,96 %)
- Настройки, боковые панели, редактор, терминал, браузер, интеграции
  GitHub / GitLab / Bitbucket / Linear / Jira, навыки, автоматизации,
  первоначальная настройка, мобильное приложение, панель агентов, системный
  трей и меню приложения
- Для строк без перевода Orca автоматически подставляет английский текст
  (см. [Известные ограничения](#известные-ограничения))

## Установка

Orca подключает языковые пакеты через систему плагинов. Укажите этот
репозиторий (или его локальную копию) как источник плагинов, установите
плагин, затем выберите **ru-RU — andreeyka.orca-russian** в
Settings → Appearance → Language.

## Как собран пакет

Английский оригинал (`en.json` из `stablyai/orca`,
`src/renderer/src/i18n/locales/en.json`) был развёрнут в пары
`путь → строка`, разбит на батчи по пространствам имён интерфейса и
переведён в несколько проходов с помощью LLM:

1. Из каталога исключены ключи защищённого пространства плагинов
   (`auto.components.settings.plugin*`, запрет реализован в парсере языковых
   пакетов Orca; нейтральные строки из белого списка
   `plugin-translatable-chrome.ts` переведены) и несколько записей, которые
   на самом деле являются inline-CSS анимированных иллюстраций, а не текстом.
2. Перевод батчами по компонентам с единым руководством по стилю: обращение
   на «вы», инфинитив для кнопок и пунктов меню, буква «ё», кавычки-«ёлочки»,
   плейсхолдеры сохранены без изменений. Названия продуктов и устоявшиеся в
   русской разработке англицизмы (`worktree`, `pull request`, `merge request`,
   `rebase`, `stash`, `diff`, команды, клавиши) оставлены латиницей, как в
   локализациях GitLab и JetBrains; `branch`, `commit`, `repository`,
   `workspace` переведены («ветка», «коммит», «репозиторий», «рабочее
   пространство»).
3. Проход на согласованность: терминология, разошедшаяся между независимо
   переведёнными батчами, приведена к единому виду (например, «ревью» для
   code review, «проверки» для вкладки Checks, «Слит» для статуса
   слитого PR/MR).
4. Проверка по тем же правилам, которые загрузчик плагинов Orca применяет при
   запуске (`parsePluginLanguagePackArtifact`): не более 20 000 записей,
   глубина до 16, безопасные ключи, отсутствие защищённых путей, строки до
   8 192 символов.

Каждая строка проверена на соответствие правилам выше; строки оставлены
совпадающими с английским только там, где это правильно (названия брендов,
технические англицизмы, код и команды, сочетания клавиш, ключевые слова
поиска).

## Известные ограничения

Часть ограничений заложена в устройстве i18n самого Orca и не решается со
стороны перевода — фиксируем их здесь:

- **Множественное число.** Orca регистрирует каталог плагина под синтетическим
  языком `plugin<hex>`, для которого у `Intl.PluralRules` нет правил, поэтому
  i18next применяет английскую схему: форма `_one` для 1, `_other` для всех
  остальных чисел. Русские формы для 2–4 и 5–20 таким образом выбрать
  нельзя. В пакете форма `_other` записана так, чтобы быть корректной при
  любом числе («Запусков: {{count}}»), а формы `_few` и `_many` добавлены на
  случай, если upstream начнёт учитывать заявленную локаль пакета.
- **Позиционные плейсхолдеры.** Часть английских строк собирает предложение
  из подставляемого английского слова (например, `{{value0}} PR #{{value1}}?`,
  где `{{value0}}` — `close` или `reopen`, или `session{{value1}}` для
  английского множественного числа). Согласовать такие фразы по-русски без
  именованных плейсхолдеров в upstream невозможно; переводы сохраняют
  плейсхолдеры и дают максимально естественную формулировку.
- **Ключевые слова поиска в меню создания вкладки.** Сопоставление запроса
  в Orca разбивает строки только по латинице и цифрам
  (`tab-bar/query-token-match.ts`), поэтому кириллические ключевые слова
  никогда не совпадут с запросом. Эти строки оставлены на английском: поиск
  по `terminal`, `markdown`, `iphone` и т. п. продолжает работать. Поиск по
  настройкам индексирует и русское, и английское слово, поэтому там ключевые
  слова переведены.
- Название пакета в списке языков формирует сам Orca как
  `<locale> — <publisher>.<id>`, то есть отображается
  `ru-RU — andreeyka.orca-russian`.
